# Employee Hours Tracker — APK Builder

Upload the contents of this package to the root of the `Employee-hours-tracker` repository.

Important:
- `index.html`, `manifest.json`, and `service-worker.js` belong in the repository root.
- `.github/workflows/build-apk.yml` must remain at that exact path.
- Commit the files to the `main` branch.
- GitHub Actions will automatically run and build the APK.
- To download it: GitHub → Actions → Build Employee Hours Tracker APK → latest successful run → Artifacts → Employee-Hours-Tracker-APK.

The APK wraps the current Employee Hours Tracker HTML, preserving the existing tracker interface and behavior.
